# CryptoMAX
Программа, позволяющая вести переписку через мессенджер MAX, используя сквозное шифрование и не отдавая телеметрию.

## Установка

Запустите скрипт cryptography.py, чтобы создать локальную пару RSA ключей
```bash
python3 cryptography.py
```

Запустите скрипт maxsecrets.py и введите данные из local storage сайта web.max.ru 
```bash
python3 secrets.py
```

Пользуйтесь.
